# Project plan

This repository develops a reproducible protein-sequence generation workflow, beginning with a transparent lightweight baseline and progressing to pretrained protein language models.

## Milestones

1. FASTA loading, validation, and dataset provenance.
2. A first-order amino-acid Markov baseline.
3. Descriptive sequence metrics and reproducible outputs.
4. Comparison with a pretrained generative protein language model.
5. Biological plausibility assessment using appropriate external tools and reference databases.

Generated sequences are computational candidates only. Sequence statistics do not establish folding, stability, function, safety, or biological activity.
